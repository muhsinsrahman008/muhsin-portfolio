# Muhsin S Rahman — Beyond the Screen

An original dark, editorial-style personal portfolio.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system and animations
- `script.js` — scroll reveals and active navigation
- `assets/mark.svg` — favicon

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. Wait for GitHub Pages to publish the site.

No framework or build step is required. Google Fonts are optional; the page has fallback fonts.

## Before publishing
Review personal details, education wording, social links and project descriptions. Add a verified CV file before enabling a resume download link.
